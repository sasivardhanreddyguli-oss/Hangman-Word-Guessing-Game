# Hangman Word Guessing Game

A console-based Hangman game written in Python.

## Files
- `hangman.py` — complete game program
- `words.txt` — English word list used for random word selection
- `Hangman_Word_Guessing_Game.ipynb` — Google Colab notebook

## Run in Google Colab
1. Open the `.ipynb` notebook in Google Colab.
2. Run the cells from top to bottom.
3. When prompted, upload `words.txt`.
4. Play by entering one letter at a time.

The game allows up to six incorrect guesses and prevents duplicate guesses from reducing attempts.
